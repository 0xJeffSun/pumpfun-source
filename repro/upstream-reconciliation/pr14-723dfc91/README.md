# PR14 lossless passive preservation

This package preserves the exact base-to-head Git delta of PR14 at `723dfc91aad7506dd7ad4840e8eb8a726264bc84`, without applying its active Relay implementation or executing its tools. The observed local `origin/main` was `0003e7fa9997c0a7acbedd0f32dfdc394f264acf`; its merge base with the PR was `294c9186895d1f2c06441b7a38706b750ac3a530`. No network refresh was performed during this capture. Git object identity is checked directly from the raw Git header and retained bytes.

The complete delta has **1,898 paths: 1,892 additions, three modifications and three deletions**. This exceeds the truncated GitHub PR files response. `preservation.json` retains every changed path, status, mode and both endpoint object IDs. Every nonmissing endpoint blob is preserved once under `objects/`, including blobs for deleted paths. Files with equal Git object IDs share one retained raw object. Raw modes preserve executable and symlink semantics without activating them.

The ten commits reachable from the head but not the merge base are retained as exact raw commit objects. These include tree IDs, parent IDs, author and committer fields, timestamps, full messages and any extra headers/signatures. The base and observed main raw commits are included as provenance boundaries; this package does not duplicate the entire Git tree or repository history. `metadata/diff.raw.z` retains the original full-ID NUL-delimited delta and `metadata/commit-order.txt` its commit order. Human-readable commit metadata is supplementary.

In total the package retains 941 unique raw blobs/commits, 135,818,055 bytes. The payload includes compressed assembly, inventories, reference roundtrip files and the proposed Relay sources as opaque Git bytes. No ELF section, original body, assembly, compressed inventory or tool payload was decoded or executed. **Reference assembly and roundtrip artifacts support tool validation; they do not prove source reconstruction byte equality. The Relay active implementation remains unselected.** This package makes no merged-state, passing-CI or deployment claim.

An initial capture stopped before reading any blob because `git diff --raw --full-index` still emitted abbreviated IDs. Its raw abbreviated delta and an explicitly author-written failure summary are retained. The successful capture used `--abbrev=40`; no initial evidence was discarded.

`collect.py` records the capture procedure and original local repository path. Do not run it as a replay verifier: it requires a matching Git object database and refuses to overwrite a completed preservation record.

Validate the sealed package with `python -B verify.py --expected-seal <manifest SHA-256>`. The verifier uses only the Python standard library and performs no Git invocation, network, archive extraction, ELF/body parsing, tool execution, compilation, runtime execution or mutation. Supply the seal from the trusted publication record. It validates all packaged file hashes, raw Git object IDs and sizes, all delta entries/modes/blob references, and the complete ten-commit parent closure to the recorded base. Full-tree membership and the original Git merge-base calculation remain capture observations, rather than independently reconstructed trees in this compact delta package.
