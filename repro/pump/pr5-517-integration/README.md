# PR #5 integration on upstream two-curve Pump source

This is a branch-specific Pump source candidate on upstream `517d77db988d8c63b6cf476f0be138c5a4f3128a`. One Anchor `multi_hop_curve_swap` entrypoint dispatches the upstream ordinary native single-curve and Tokenkeg two-curve orders to `multi_hop_curve.rs`, and the recovered token-quoted, Token-2022 and richer routes to `multi_hop_curve_swap.rs`. The dispatch is bounded by the saved fixtures; it is not a general proof that every malformed or mixed route selects the correct branch. Claim, admin incentive and Mayhem virtual-params source additions remain separate PRs.

Two independent clean-target Agave 2.1.21 SBF platform-tools v1.44 builds used identical **37** compiler-input source hashes, identical SDK and rustc hashes, and produced the same **1,679,528-byte** ELF, SHA-256 `c7292be9c92690f0b4f19603411c7e7f76e0c2a3dbc4a0239141cb2f7e30b786`. The captured Pump ProgramData is SHA-256 `7a19affaa2c6187e04a5fe0ea298cee81fa5eb8c24cfcc30d85f615e89f7b02d` and has a **1,934,800-byte** ELF. This candidate is **255,272 ELF bytes shorter** and differs from byte 24; it is not a byte-identical or deployable replacement.

On that exact candidate ELF, signed offline target/candidate comparisons match upstream native **56/56** (50 reach Pump), upstream ordinary two-curve **20/20** (18 reach Pump), recovered core **34/34**, recovered route matrix **72/72**, inherited QuoteControl **507/507**, and volume sync **341/341**. The six suites contain **1,030 paired cases and 2,060 verifiable outer signatures**. The [receipt index](receipt-index.json) hashes both build attempts/comparisons/logs, the candidate, all six raw compressed receipts and the retained harness files. The [read-only verifier](verify_package.py) checks source/build identity, saved signatures, watched account states, errors, events, inner instructions and return data. It does not execute SBF or verify untested routes.

The upstream two-curve harness had a hardcoded 36-file source count and an adjacent generic build-attempt filename. The [retained copy](harness/pump_tokenkeg_two_curve_differential.py) changes only those two provenance bindings to accept this 37-file branch package; its fixture is copied byte-for-byte. The recovered core/route harnesses originate from the earlier [draft PR #5](https://github.com/lalalune/pumpfun-source/pull/5) `d71c78a`, with only repository-root discovery and imported-harness hash attribution adapted for their retained package location. The original target and all token/account fixtures are unmodified. The earlier `pr5-current-upstream-integration/` package remains a historical checkpoint for its different `4c80e0c7…` ELF, not evidence for this ELF.

```sh
python3 repro/pump/pr5-517-integration/verify_package.py
```

The packaged 20-case and 34/72-case harnesses can also be replayed against `candidate.so`; the README and Python files pin their inputs. Other inherited Pump suites and Surfpool were not rerun on this ELF. All fixture accounts and funding are local/synthetic, with a captured PumpSwap AMM used for genuine local CPI signing. No public transaction or real funds were used.
