# Metaplex handler and dispatch source trial

This unbuilt eighteen-file patch extends the [twelve-file trial](../metaplex-validation-source-recovery/README.md) that produced candidate9. It includes nine behavioral differences supported by [static control and account data flow](static-mapping.md), two redundant zero-use branch shapes, and the observed mint-before-metadata owner-check order in SetTokenStandard. The exact public baseline remains `17e99434af5ead3e989c08f32af33609821d0bc0`.

Recovered changes concern delegation checks, close-authority token-standard guards, self-transfer no-op ordering, desired token-standard equality, explicit system-program checks, and owner-check order. The static report identifies each original instruction range. The two unsigned zero-use guards express observed branch structure; exact historical source spelling is unproven. No new behavioral coverage is claimed for this trial. The additional runtime-fixture task was stopped before dispatch and is not part of this package.

Root verified all incoming source hashes, then moved only the existing SetTokenStandard mint-owner check before metadata ownership. The complete patch was independently applied to eighteen pristine public files and every resulting hash matched `source-inputs.json`. `source-snapshot.tar.gz` retains the proposed Rust files. `static-evidence.tar.gz` preserves the original mapping diagnostics and the separately observed owner-check order. `agent-source-manifest.json` describes the immutable pre-ordering handoff; `source-inputs.json` binds this final combined trial. Upstream licensing is retained in `upstream-LICENSE`.

Build with workflow input `token_metadata_dispatch_recovered` (or the matching `--metaplex-dispatch-recovery` builder flag). The original ELF is read only after source compilation for comparison. No executable, header or relocation patches, padding of Rust source, flag searches, or signer bypasses are involved. Successful source compilation, prior-case regressions and whole-file equality must be reported separately. This source hypothesis is not a production substitute or a complete security assessment.
