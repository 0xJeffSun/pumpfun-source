# Combined review of PRs 1–7

This package binds the combined source to two clean v1.44 builds and fresh bounded differential replays. It integrates claim and admin incentives, the synthetic Mayhem virtual-parameter handler, and richer curve routes while retaining the newer upstream native-route parser, fee selection, validation order, and generalized Tokenkeg routes. The refreshed candidate also retains upstream's full BondingCurve creator codecs and mutation/log ordering. Event serialization uses a separate SBF frame: the first integration build exposed a two-curve stack access violation, and the fixed build passes the same route matrix.

The build remains a partial reconstruction, differs from captured Pump, and is not a deployable replacement. Incentive state is synthetic. The positive Mayhem caller is a synthetic local program; deployed reachability of `set_mayhem_virtual_params` is unproved. Existing transfer-fee, arbitrary-input and historical-source limits remain. Surfpool was not rerun. Older PR and upstream binaries and receipts remain historical; none are attributed to this candidate.

`receipt-index.json` lists 9,558 fresh paired cases: 9,269 inherited cases, 60 claims, 98 admin incentive cases, 25 synthetic Mayhem cases, and 106 recovered route cases. The historical scripts' `baseline_commit` fields describe their original fixture baseline; the complete current compiler input map is `source-map.json`, and both build reports bind the actual combined source.

`run_suite.py` adapts source-binding checks in the frozen 37-input route/create harnesses to the complete current source map. It also handles a LiteSVM 0.27.1 fixture-installation difference: when a captured executable account points to absent ProgramData, it wraps the VM's existing bundled token executable bytes at that address before restoring the captured program account. This does not substitute either Pump executable, disable signatures, or change the tested instructions. The shim and original harnesses are retained and hash-bound.

The separate Fees fresh-init package verifies 21 saved signatures. A fresh local replay matches its state, errors, return data and transaction bytes; platform compute-meter values differ, so the historical receipt is preserved. Mainnet Mayhem trade evidence and direct-call signer rejection verify separately. No public transaction or deployment was made.
