## R1 control flow, identities and errors

At original 0x5c488, the saved flag is ANDed with 1. The signed branch at 0x5c498 skips to 0x5c5c8. Thus flags 0 and 2 skip the helper, flags 1 and 3 call it; neither direction, last-hop status nor eventual fee amount changes this gate. At 0x5c5a0 r4 is zero. Call bytes `85 10 00 00 dc 43 00 00` at 0x5c5a8 resolve to 0x7e490. The new call at source lines 291–295 is immediately after vault admission and before direction selection. The instruction annotations contain misleading destinations; signed encoded operands govern this review.

Caller slot A+0x38 is the same raw writable buyback recipient used later in settlement. Global is the decoded wrapper+8; quote mint and selected token-program keys are stack copies passed through outgoing -4096/-4088 slots. The ordinary mint fences and typed Token program make the supplied `a.token_program.key()` Tokenkeg. Native stored-zero curves still supply the quote account key WSOL, not the stored zero key. No scalar bypass, owner exception or native shortcut has been introduced.

## API, type and borrow assessment

No concrete API/type/borrow blocker was identified by static inspection. No compiler, rust-analyzer, typechecker or macro expansion was run. Dependency source/cache was not searched. Anchor 0.31.1 and anchor-spl associated-token/token features are frozen inputs; public API contracts are bounded premises rather than a new dependency audit.

`&a.global` can deref-coerce through Box and Account to Global. Temporary AccountInfo and Pubkeys at the synchronous preflight call live to the end of that statement; the helper returns no borrowed value. TokenAccount decode yields an owned wrapper; copying its Pubkey authority out cannot retain the Ref. `require_keys_neq!` is the prelude key inequality macro, and both Pump variants are present in the frozen error enum. The fully qualified ConstraintSeeds variant is compatible with the same key-equality pattern already used by vault admission.

FeeConfig/Fees/FeeTier have required Clone and AnchorDeserialize implementations in frozen trade_types. TradeEvent fields and their supplied primitive/Vec/String values correspond to that declaration. Explicit Context lifetime matches the frozen one-line public wrapper. `remaining` owns only the slice cursor; try_accounts may produce `'info` handles without borrowing the temporary BTreeSet past its call. `PreviousHop` owns AccountInfo clones, not references into `h`. Seed arrays remain alive through synchronous invocation. Curve immutable borrow ends before mutation, and mutable `c` ends at its final store before later whole-account access under Rust nonlexical lifetimes. RefMut lamport temporaries end at each assignment. These are concrete plausibility arguments, not compiler proof or a guarantee against generated stack-size diagnostics.
