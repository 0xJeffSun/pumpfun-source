# Relay Owned Review

The unchanged original review and seal are retained under `original/`. Run `python3 -B verify.py --repo /path/to/repository`. The wrapper checks every payload, then repeats the original static checks in a disposable copy. For the IDL selection it authenticates each complete selected body. No build, target transaction or source edit occurs. Historical `work/` references in reports remain provenance; any operational path adaptation is listed in `execution.json`. These source observations do not establish whole-program or recursive data equivalence.
