# Fees legacy/V2 sharing residual review, pass 2

Reviewed six distinct candidate residuals in the existing legacy/V2 sharing caller and payout evidence. **No new source change is justified by the examined evidence.** Three suspected semantic/error-order differences are already represented in source. The remaining ownership/function-boundary questions are genuine reconstruction gaps, but the available proof does not select a natural correction without guessing historical types or optimizer behavior.

This pass does not repeat the prior paired-account bounds/key check. It uses only the accepted `repro/pump_fees/v2-caller-v144` evidence (candidate `b2d02994dbc29680273f0a3589d8d9fd2763445505483c1acbd4c9f09e1502fb`, symbols `4a3ea0102ef726e0b0666ab10e659147dc22ba3f59e1692a9213fb7304049532`, original `4f2955d0f6b40cc9ff7daa18ccad7d19119ba1249759f4e7e3bb691beee6b35e`) and its bound source. There are no main edits, builds, runtime cases, new transactions, compiler/layout trials or invented diagnostic coordinates. Prior reports and the AMM publications remain untouched.

## Retained proof and checks

`selected-proof.json.gz` contains complete original/current windows, all selected instruction/data records, actual handler call paths, direct-target inventories, and the original legacy adapter/finalizer roots. `windows/` contains complete disassembly for the V2 caller, authorize, preprocess, both payout helpers, final validation and Pump adapter. `input-bindings.json` pins the entire source evidence packages, original/current binaries and current source. Source files are copied here only for review.

`verify.py` checks input hashes, every retained instruction byte, complete root raw hashes, and the specific original/current ordering witnesses. It does not execute either target. Passing these checks does not prove arbitrary branch feasibility, full adapter equivalence or recursive data-object identity. In particular, structured data pointer `0xc3e94` is not read as a guessed UTF-8 error string; unclosed data extents remain unclosed.

The original inventory remains 585 windows: 453 mapped, 130 unattributed and two call conflicts. This pass claims no additional matched window, completed handler, semantic coverage or historical source recovery. A useful next step must supply missing branch-sensitive ownership or historical source evidence; there is no authorized build-worthy patch from this pass.

Published verification: run `python3 -B verify.py --repo /path/to/repo`. The original verifier and manifest remain alongside the path-portable wrapper; publication changes no target or source analysis.
