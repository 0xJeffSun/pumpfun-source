# Relay source build 02: emitted ELF with blocking stack diagnostics

This is an immutable diagnostic build, **not a clean or executable candidate**. The one authorized corrected-launcher build returned 0 and emitted both ELF files, but LLVM reported **301 stack errors in six functions**. The maximum reported frame is 7,552 bytes against the SBF 4,096-byte limit. No target execution, transaction fixture, runtime comparison or deployment occurred. The ELF must not be treated as validated merely because the process exited successfully.

The 21 source/lock inputs remain identical to the frozen preflight. Compilation used the existing platform-tools v1.44 request and pinned tools; the unmodified SDK selected v1.52 for its strip phase. Before/after tool hashes, SDK file bytes/modes, source maps, commands, complete stdout/stderr and dependency-source records are retained. These are file and phase witnesses, not a complete child-process invocation trace or evidence of the historical original recipe. All allocated sections of the stripped ELF equal the unstripped ELF exactly. Generated keypair contents were excluded before reading; only its basename is recorded.

The static inventory exhaustively covers the original `.text` with 492 retained **inferred** windows and candidate `.text` with 289 distinct complete symbol windows (303 actual STT_FUNC symbols including aliases). There are no gaps or overlaps in these enumerations. Twenty-nine original windows have a raw complete-body candidate match. In-memory normalization of direct-call displacements and relocation-backed `lddw` address immediates finds 112 original windows with a complete instruction-shape match, leaving **380 unmatched**. Branches, non-relocated constants, register choices and external-call encodings are preserved. No executable bytes are modified.

`match-witnesses.json` lists every match, direct target pair, recursive call-shape closure and bounded data comparison. These are **not semantic equivalence results**: 64-byte data prefixes do not prove object extent, indirect targets/ABI remain open, and aliases or tiny duplicate bodies can produce several candidate matches. Even a raw caller match does not independently establish its callees. `whole-file-residuals.json.gz` retains every positional difference plus the complete unmatched tail; `section-comparison.json` also separates section bytes and lengths. There are 262,176 differing common-position bytes and a 354,584-byte original-only tail.

The complete original preflight and first launcher-failure correction packages are archived under `prior/` with unchanged seals. The original precompile failure (`cargo +solana` incorrectly reaching direct Cargo) remains negative evidence. The corrected launcher differs only in its approved proxy validation and PATH ordering. Its historical header still says unexecuted because those sealed bytes were deliberately not rewritten after this run.
