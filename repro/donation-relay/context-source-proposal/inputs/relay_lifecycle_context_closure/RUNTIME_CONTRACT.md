# Bounded runtime contract for lifecycle.py

This is an implementation boundary, not a supplied always-success runtime. The proposal is usable only when these operations are implemented with real framework/runtime semantics. No target execution was used to validate this contract. Normal-resource control flow is recovered; allocator aborts, alias-sensitive borrow timing and historical diagnostic identity remain imports.

`consume_typed` takes exactly one account in ORDERS order; missing account is 3005 at that point. Raw/Unchecked retain AccountInfo without adding owner/address/executable checks. Signer must inspect the real `is_signer` flag (original AccountInfo +40); failure 3010, not an equality check against a replacement key. Writable checks inspect +41 later. Consume all declared fields before deferred init/constraints, preserving remaining account order.

EpochTracker, Debouncer, Distribution and SwapReceipt are checked relay-program accounts: preserve the System-owned/zero-lamport uninitialized rejection, account owner admission, borrow, discriminator then body parsing, and propagated error metadata. Typical framework codes are 3012 uninitialized, 3007 wrong owner, 3001 discriminator prefix missing, 3002 mismatch, 3003 body failure. State tags 0/1 decode; context parsing does not require Initialized. Referenced field order is the frozen IDL. `decode_program(checked=False)` skips the discriminator match only; it does not skip owner/uninitialized, borrow, or body decoding. It must read a body after the discriminator prefix; do not invent defaults for malformed initialized storage. The proposal's size parameter controls allocation, not a general exact-size admission rule; only whitelist has an explicit exact 1037-byte check.

InterfaceToken/BoxMint admit the token-interface owner set, borrow and deserialize using the original token-interface contracts; the chosen program equality checks are later constraints. They must reject malformed data and preserve supported extension/base-state semantics. `BoxMint` additionally has the original successful allocation premise. No permissive token decoder or invented token-extension policy is supplied. TokenInterfaceProgram admits supported token program IDs and executable status. ATAProgram and SystemProgram require their real IDs and executable flags: key failure 3008 precedes executable failure 3009. The event `program` field and Jupiter are Unchecked at consumption; Jupiter receives only the explicit address constraint later.

Key and seed methods use actual 32-byte public keys. `find_program_address` derives under executing relay program, returns canonical bump; `create_program_address_or_constraint_seeds` uses the supplied stored bump and maps derivation failure to 2006 before key comparison. The associated address derives under the ATA program from authority key, token-program key, mint key, in that order. Preserve seed lengths, little-endian 16-byte epoch and one-byte bump. Do not require canonical stored bumps on existing accounts where the original uses create_program_address.

Rent acquisition can fail before any constraint relying on its result. `is_exempt_observed` clones/reads lamports, obtains data length with the original borrow behavior, then tests rent exemption. Lamports and data observation order is material. `minimum_balance` supplies the actual runtime rent calculation, including its floating-point implementation; it is not a hardcoded balance or newly introduced economic policy.

System create: payer writable signer; new account writable signer via the original PDA seed group; data encodes CreateAccount(lamports, space, relay_program_id). Transfer: payer writable signer and target writable, with **no PDA signer group** in the funded branch. Allocate: target writable signer, requested size, signed by PDA. Assign: target writable signer, owner relay_program_id, signed by PDA. Keep helper CPI order and actual errors. A funded already-owned receipt is not accepted just because its codec would decode: allocate/assign must succeed first. Refcount/borrow/panic paths and external System behavior are not flattened into framework 2004 or success.

ATA Create has byte data `00`, targets the actual associated-token program, and six ordered metas: payer (writable signer), canonical ATA (writable nonsigner), authority (readonly nonsigner), mint (readonly nonsigner), System (readonly nonsigner), token program (readonly nonsigner). Authority is distribution. Outer writable mint constraints do not turn the CPI mint meta into writable. No relay PDA signer group is supplied. AccountInfo target must resolve to the canonical meta; the passed wrong-address account cannot be silently substituted. ATA program validates/creates under its own signer authority. Both fresh and prefunded System-owned targets enter the same genuine Create CPI; existing initialized targets also enter Create, not a local reuse or idempotent success branch. Downstream ATA/token/runtime failures remain their actual errors. Decode created token account only after successful CPI. Output ATA parser checks writable and rent after decode; it does not separately perform the existing-vault owner/authority/address sequence.

`rt.error` must implement framework vs custom conversion and account-name/compared-values attachments. `equal` uses compared keys for key constraints; source numeric codes alone are not the historical rich error ABI. 2022/2023 relationship failures in these parsers have no account-name attachment; 6033 carries `swap_receipt`, without compared keys. Error allocation/destructors, diagnostic locations, all unusual alias failures and panic payloads are outside the normal-resource hypothesis. Do not fabricate historical source paths or line numbers.

The enclosing instruction supplies original wrapper argument decoding, relayer business helper105, actual body implementation, event/return serialization, account exit and transaction rollback. A parser failure can follow rent-funding CPI; it must roll back at transaction scope. No parser-only return is instruction success. Exits and mint-policy106 are separately owned and are not replaced here.
