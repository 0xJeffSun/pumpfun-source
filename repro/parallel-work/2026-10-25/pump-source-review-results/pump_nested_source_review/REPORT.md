## Findings and build prerequisites

1. **Evidence packaging gap, repaired additively here.** The proposal's [byte ledger](inputs/hypothesis/byte-source-map.json) contains the fold and wide runtime slices, but does not itself include `0x61348..0x63940`: initial scaling, final scaling, constant-product, Curve conversion, and two error helpers. Its [inherited pricing inventory](inputs/hypothesis/evidence/closure/prior/inputs/pricing/windows.json) names these bodies. I retrieved the identified original interval with `git show`, bound it against the full original ELF, and reviewed [the actual instructions](inputs/bytes/61348-63940.asm). Keep this supplementary binding with the build decision; do not describe the earlier portable verifier as having checked those missing bodies. This is a publication defect, not evidence that the pricing source is wrong.
2. **Preservation is not equivalence.** The unchanged fixed context and post-selection code still import initialization, quote ATA creation, metadata calls, minting, authority revocation, event CPI and account-exit behavior. The [context report](inputs/hypothesis/evidence/closure/REPORT.md) explicitly leaves exact initialization CPI builders and post-init decoders incomplete. Carry these as bounded premises into the one-build experiment. A build cannot discharge them. Any acceptance claim needs the normal-operation comparisons below, especially after taking formerly rejected deeper/Pool routes.
3. **Static API review passed with a dependency boundary.** Actual checkpoint `BondingCurve`, `Global`, `PumpError`, caller signature and Cargo declarations were inspected. External dependency source was not fetched or read from caches. Anchor 0.31.1/Borsh, AccountInfo borrow behavior, PDA APIs and u128 lowering remain explicit library premises; this is not a compiler certificate. No visible missing field, private-item access, escaping borrow, module-path error or new lifetime mismatch was found. Do not widen this statement to a successful typecheck.

No stricter positional-depth, cycle, exact-tail-count, Pool mint-field, vault mint/authority, or ancestor eligibility checks should be added on this evidence. They would change the recovered local behavior. Full allocator/libc closure is not a prerequisite to trying this natural source.
