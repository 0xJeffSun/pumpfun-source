# Unsupported and conditional obligations

The business walk and pricing source is concrete. These remaining obligations qualify promotion; they are not TODO implementations, invented guards, or a reason to collapse the walk to depth one.

1. **Framework/runtime ABI.** Frozen `programs/pump/Cargo.toml` pins Anchor/anchor-spl 0.31.1. Standard `Pubkey::find_program_address`, `AccountInfo::try_borrow_data`, Anchor/Borsh primitive decoding, error macros, and existing CPI calls are valid source hypotheses. Their precise machine lowering, Rc/RefCell layout, allocation/refcount overflow, borrow error conversion, panic behavior, error logging and dynamic data are not independently proven. The five-slot enum is not a repr/size parity assertion. u128 lowering imports the manual positive-denominator arithmetic argument, not compiler equivalence.
2. **Initialization.** Original context invokes mint 0xb0158, curve 0xb3b90, ATA 0xb54d0. Lamport-dependent create/top-up/allocate/assign arms, exact CPI data/metas and all downstream decoders remain partial. Post-init mint 0x1862f0, ATA 0x185ed0 and curve 0x9b430 must not be replaced with this ancestor decoder without separate evidence. Original owner-before-borrow/decode order and generated macro validation order require review before promotion. No custom initialization runtime is supplied.
3. **Error data.** Numeric business errors and local branch order are grounded, including parser decoder failures mapped to 6099. Their historical names, source locations, compared pubkeys, account-name annotations, underlying decoder error destruction and allocation order are not reproduced exactly. The decoder directly creates the outer business error rather than reconstructing opaque intermediate error allocations. Framework borrow/PDA error conversion remains conditional. No source coordinate padding/spoofing is used.
4. **Caller scope.** Source changes reconcile quote program/selection/owner and relevant prefix routing only. Preexisting creator, cashback, metadata and later CPI/event paths remain frozen and are not newly certified. Token-2022 quote extension helper code is preserved; its opaque original decoder 0x1a918 and extension compatibility remain unclosed. No stopped v3-extension or Metaplex investigation is resumed. Native roots with Tokenkeg quote admission do not depend on that extension decoder; all creates still depend on ordinary Token-2022 mint initialization.
5. **Resource/alias effects.** Borrow scope/order is represented explicitly, including terminal control and all three Pool borrows. Full instruction acceptance under arbitrary aliases, failed allocations or CPI effects is not implied by the absence of a local trailing-count/depth check. The source uses ordinary safe framework borrows; it does not synthesize RefCell state or bypass signer requirements.
6. **Artifact equality and compilation.** This is uncompiled source. Typechecking, stack/resource feasibility and source integration require independent parent review followed by separately authorized builds. No original Rust spelling, optimizer shape, ABI layout or exact binary is claimed. No dependency, compiler flag, version or path search was performed.
7. **Frozen evidence limits.** Portable verification rechecks copied subsets and bounded bytes, not uncopied historical manifests as if complete packages. Optional frozen-repository verification closes full Git membership and byte extraction for this checkpoint. Reports remain manual interpretation. Independent review's 36 objects/211 slices is its own unchanged evidence, not an inflated count for this proposal. Slot7/A+0x38 remains only writable raw AccountInfo locally.
