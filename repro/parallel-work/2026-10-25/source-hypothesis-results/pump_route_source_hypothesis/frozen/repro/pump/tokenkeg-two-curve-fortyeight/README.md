# Ordinary Tokenkeg two-curve partial recovery

The current Pump checkpoint retains **48 bounded implemented handlers and five partial paths**. It extends partial `multi_hop_curve_swap` to exactly SOL→A→B and B→A→SOL, with ordinary Tokenkeg accounts, canonical pre-existing vaults, a native root storing quote zero, and strictly non-completing buys. Only `programs/pump/src/multi_hop_curve.rs` changes from the [prior serializer checkpoint](../bonding-curve-serializer-fortyeight/README.md). The program README is updated separately and preserved here. Other instruction sources are unchanged.

The candidate is **1,576,744 bytes**, SHA-256 `5c1c1c2d1cd2c334b3e054b6a8fb5ac0638d80d13495c1c18d935ad20bfd62bb`. One scratch and one main build independently used the fixed offline/locked recipe with 36 source inputs. Their complete ELF files are identical. The selected compiler/linker is v1.44; the installed CLI SDK's unchanged stripping script uses v1.52 `llvm-objcopy`. `toolchain-phases.json` distinguishes these phases. No compiler/source/flag variants or executable patches were used. Full equality with the captured original, historical source/toolchain reconstruction and the security audit remain incomplete.

All **9,237 differential comparisons across 38 suites** pass: 9,217 established cases plus 20 new two-curve cases. All 28 established Surfpool runners also pass **1,024 comparisons**, with 2,048 transactions and 2,980 verified signatures. Core differential receipts contain 15,870 transactions and 24,256 signatures. The 66 core receipts identify their executed scratch ELF and actual scratch compiler inputs, then bind the independently built identical main ELF. Embedded legacy source maps remain incidental baseline checkout snapshots. Quote-control directly binds the scratch build it executed. No runtime receipt is inherited from an older executable.

The serializer claim is freshly recomputed against this candidate and its symbols: the complete 1,840-byte BondingCurve exit at candidate `0x7110` matches original `0x5a28` after only actual relocation/internal-call normalization, all 25 direct callee bodies match, and the exact eight-byte discriminator matches. This is not inherited from the old candidate offsets. `match-serializer.py --check` recomputes the saved report without writing program files. Transitive rodata identity is not established.

The 20 new comparisons cover both route directions, two positive input sizes and four fee configurations: saved synthetic-fixture fees, nonzero exotic fees, zero-exotic fallback, and legacy flat fees. Sixteen succeed. Two stop at AMM's zero-input check; two execute Pump successfully before AMM's final slippage check rolls back the transaction. Eighteen comparisons per side contain genuine captured AMM→Pump CPI with 23 accounts. All 40 outer signatures verify normally. Previous-curve vault authority, endpoint flags and native versus flat/exotic fees are independently traced; state, balances, transfers, events, return data and normalized logs match. All curve/vault/volume state is explicitly synthetic and pre-existing. No initializer or direct signing of AMM's GlobalConfig occurs.

The earlier 56-case native one-curve subset is retained unchanged: 50 comparisons reach Pump, six stop in AMM and 11 succeed. Together the two routing subsets contain 76 cases, 68 Pump CPI comparisons, eight caller rejections and 27 successes. These finite fixtures do not establish general routing equivalence. Arbitrary hop counts, other quote currencies, Token-2022/extensions, v3 route expansion, holder/cashback/Mayhem modes and completion remain unsupported. The separately documented current sell_v2 transfer-fee boundary mismatch remains unresolved; this candidate is not a deployable replacement. Stopped incentive, trade-fee, extension and initializer lanes were not resumed.
