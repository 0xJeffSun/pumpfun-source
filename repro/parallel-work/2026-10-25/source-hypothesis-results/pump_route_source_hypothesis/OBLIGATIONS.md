# Remaining recovery and conditional substitutions

This is a general route implementation within the ordinary domain, not an all-input replacement. It has no fixed depth/direction/flag-vector restriction. Repeated/aliased accounts are not rejected by an invented guard; their successful global behavior is not claimed. Equal-key previous input retains the recovered no-CPI shortcut. No completion, holder, cashback, Mayhem or extension body is supplied.

1. **Scope fences.** ReconstructionBranchUnsupported checks explicitly limit mint data to ordinary 82-byte Tokenkeg, typed source/destination/base vault to ordinary 165-byte Tokenkeg, nonzero quote vault to its ordinary decoder path, curve data to at least 166, non-holder mode, and buy output strictly below real reserve. These are labeled proposal scope fences inherited from the bounded task, not recovered original admission conditions. Complete/cashback/Mayhem handling is not expanded. Short original curve layouts may fail in the unchanged BondingCurve decoder before reaching the preparation fence. This is an acknowledged missing decoder/resize implementation, not historical equivalence. Scope-fence failure order is not asserted to match the original.
2. **Context/types.** Anchor context declarations express the recovered thirteen-slot contract including mandatory Token-2022 program identity/executable and event PDA bump. Full Global/BondingCurve decoder versions, every generated reader's ordering/cleanup, event_cpi macro expansion and ownership/error details remain conditional. The new fee wrapper does eagerly deserialize both vectors and all three exotic words before PDA/handler checks, without optional-field defaults. Its Borsh allocation policy is not claimed to reproduce the original initial min(count,102) capacity/growth. No vector sorting or fee caps are added.
3. **Arithmetic/errors.** Unsigned u64 products and positive u128 division follow the retained manual CONTRACTS.md proof. u128 wide denominators preserve carry. The ordinary product domains make some high-result failure arms impossible; natural u128 expressions/narrowing preserve the supported business result. Error variant names are reconstructed-source choices corroborated where available, not proof of original serialized error data, compared-values payload, file/line metadata, formatting, cleanup or termination. Buyback assertions preserve the two terminal predicates/order; Rust panic's implementation is not claimed identical to the original terminal helpers. ProgramError::ArithmeticOverflow is a proposed SDK mapping for the native failure, not a proof of raw sentinel conversion. No allocator/error closure is required to write the business source; it remains required for stronger runtime equality.
4. **Native rent/preparation.** Source uses locked Rent::get/minimum_balance as a conditional realization of original returned word M. The syscall identity is bound; floating conversion/multiplication/rounding/saturation behavior is not fully proved. Original zero-quote protected balance is checked creator+protocol, then real quote; available=max(lamports-protected,0); top-up is M-available only when M>available. In particular it is M, not M plus a liability deficit, when lamports<protected. The nonzero quote path retains initial protected=0: rent_prepare instructions 0x3d2c8/0x3d2e0 branch directly to 0x3d4b8. This is a bounded new source composition from an already admitted helper, not a new callee. Short resize remains unimplemented and explicitly fenced. No exact rent value is assumed.
5. **Native input and self-CPI.** Source-to-curve native funding uses context user without enforcing user==source_authority. System builder key/metas/data/two infos/empty seeds are established; full caller r7 reaching definitions remain open. Native buyback moves lamports, invokes the exact 8-byte self payload with three infos and the validated event bump, then invokes SyncNative with one info. No self-body was read; no “flush” effect is claimed. Raw slot 7 is not locally a proven token account. Runtime authorization, borrow behavior, external System/Tokenkeg execution, rollback and self dispatch are imported dependencies.
6. **Transfer/events.** Four-info Tokenkeg TransferChecked interfaces and prior/current curve seed identities are grounded. CPI processors can reject locally admitted frozen or wrong-authority token states; no local authority/frozen/balance guard is fabricated. The proposal uses the pinned instruction builders and invoke APIs, whose generated allocation/cleanup/error paths are not exact-original proofs. Event object values, fixed string, discriminator/schema, log-before-self-CPI and one readonly signer meta are grounded. Anchor serialization and Vec allocation are conditional realizations. Final-u64 adapter-difference meaning is confined to the ordinary path, where it is zero. No historical field name or extension economics are asserted.
7. **General route claim.** The loop and successful ordinary per-hop identity/authority transition generalize to arbitrary structurally admitted depth; resource limits remain external. Native endpoints are root endpoint hypotheses; arbitrary native transitions inside cyclic/mixed routes, aliases/repeated curves and modes are not certified. They are not made easier by adding rejection guards. No new >2-hop runtime observation exists. Completion/synthetic second accrual and all excluded bodies remain untouched.
8. **Review/build boundary.** No compiler/typechecker, runtime or test suite was run. Parent must review source/API compatibility, context derive behavior and each condition before separately deciding any build/tests/promotion. This proposal does not modify accepted handlers, source checkpoint, binaries or audit counts.
