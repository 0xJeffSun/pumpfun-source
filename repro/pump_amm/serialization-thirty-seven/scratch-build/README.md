# AMM37 GlobalConfig serializer correction

This isolated candidate changes only `GlobalConfig::try_serialize`: normal `?` conversion now handles the discriminator write and Borsh serializer result. It replaces the explicit `ProgramError::BorshIoError(err.to_string())` mapping. The unchanged AMM37 compiler/lock inputs use platform-tools v1.44. No `create_config` source is integrated, and the recovered instruction count stays 37 of 38.

The clean candidate is 1,176,640 bytes, SHA-256 `b656628b9f43c1b18edecbe58f8275be3829c52604a1926f540dcdb64eb8f257`. It is 920 bytes smaller than AMM37. Its complete 1,648-byte GlobalConfig exit matches the original body at `0x4f00..0x5570` when only actual relocation immediates and relative internal-call offsets are masked in memory. Relocation patterns and every direct call target's complete bounded body also match. This comparison does not establish transitive rodata equality or full binary equality.

All 25 existing AMM37 suites were freshly run against this exact candidate: 17,462 cases, zero mismatches. These are repeated inputs against new executable bytes, not additional unique fixture coverage. The frozen test helper and captured runtime hashes were checked before and after execution. No live transactions, privileged-signer bypass, executable patches, source padding, compiler-flag search or dependency changes were used.
