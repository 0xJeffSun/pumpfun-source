# Legacy buyback-recipient validation recovery

The deployed AMM rejects the zero public key as a buyback recipient before list membership and ATA checks. The prior maintained legacy buy/exact-quote buy/sell implementation checked membership and ATA only. A configured zero entry could therefore pass the reconstruction and succeed where the deployed contract returns error 6053. Even when another check rejected it, the reconstruction omitted the original Left/Right zero-key diagnostics.

The restored `GlobalConfig::validate_buyback_recipient` checks the nonzero recipient with `require_keys_neq!`, then membership, then the expected ATA. Both legacy handlers call it. The original 2,320-byte helper at `0x62e68` and the Rust-built helper differ at just six normalized instructions: three source-line constants and three source-path lengths. No padding, copied instructions, or forced compiler layout was used. These metadata differences still prevent a full window match; data-reference and whole-program identity remain unproved.

`probe.py` uses genuine signatures on local synthetic transactions with captured token/fee dependencies. It tests buy, exact-quote buy and sell, zero/nonzero recipients, absent/first/last list membership, zero/full buyback rates, and valid/invalid ATA addresses. Of 72 cases, the prior build has 36 mismatches, including 12 false successes. The recovered candidate has zero mismatches across return errors, complete logs (except compute and source coordinates), events, CPI records, return data and account snapshots. The transactions and original observations are retained.

The source-bound Linux v1.44 build has 539/785 normalized window matches, 113 raw matches and 246 unmatched windows. Its SHA-256 is `b58374f0b126162e540cc1a3718288be52085a4f88df63c2238232878516f14b`; whole-ELF equality is false. `results` also retains the full 25-suite regression corpus (17,462 cases, 35,074 transactions, 35,418 signature fields). Existing recorded log coverage is preserved; older suites with incomplete log capture retain that limitation. Earlier focused proofs are inherited from the independently verified predecessor, not claimed as new executions here.
