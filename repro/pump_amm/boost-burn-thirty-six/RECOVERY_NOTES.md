# AMM boost_buy_and_burn scratch recovery

This isolated lane extends the published AMM35 candidate. Main AMM source is frozen. Captured original binaries and dependency binaries are executed unmodified in LiteSVM; the payer and configured boost authority are local test-owned signers. Global authority, boost balances and selected pool fields are synthetic fixture changes, not claims about reachable production state. Every constructed transaction verifies its signatures before submission. There is no network transaction or privileged PDA signer substitution.

Original static mapping: wrapper 0xe4738..0xe4c68, context 0x8d7d0..0x90068, body 0x1fed8..0x22c80, exit 0x90068..0x90660. Read-only excerpts and hashes are saved in static-evidence.json. The authority verifier at 0x62688 rejects zero/mismatched global boost authority; 0x6c248 treats checked effective virtual reserves as nonzero only when the addition succeeds. Fee accrual overflow is therefore classified PoolCannotBoost before the later pricing checks.

Observed execution order: configured authority; boost enabled; buy disabled flag; effective virtual reserves; min(requested, boost vault balance) positive; quote transfer-fee net amount positive; real vault covers accrued fees; effective quote reserves fit u64; constant product base output using net quote minus one; positive base output; slippage; base output less than reserve; signed quote transfer from boost vault; signed pool base burn; reload balances and supply; BuyEvent and BoostBuyAndBurnEvent as log and event CPI pairs; if boost vault is empty, optional Token-2022 withheld-fee harvest and signed closure to the authority.

The trade event uses the boost PDA as user, the boost vault as user quote account, zero fee/volume fields, pre-trade vault balances, net quote spent, post-burn base supply (fixed 1e15 for Mayhem), unchanged pool creator fees, and quote transfer fee. The boost event uses the actual configured authority and gross quote used. The pool account is readonly and its bytes remain unchanged.

Original error 6088 QuoteMintNotWritable is absent from the supplied IDL. An empty Token-2022 boost vault with a transfer-fee configuration requires a writable quote mint even when the computed transfer fee is zero, then calls harvest-withheld-tokens-to-mint before close. Earlier original-only probes deliberately used enlarged extension data with captured lamports, which can trigger the runtime rent check over the program's own late error; those receipts are retained, while differential fixtures fund enlarged mint/vault accounts explicitly.

Build 01 failed with borrow-check errors around the two event CPI emissions. Its exact source archive, build attempt and log are retained. No executable was produced. The corrected draft also uses original TooLittlePoolTokenLiquidity (6003) for the output-reserve bound.

Finite original/candidate comparisons are not full-program equivalence or proof of historical source. Remaining missing AMM IDL instructions are create_config and multi_hop_swap after this handler is validated and promoted. The fixed create_config signer is not bypassed.
