# One fixed Linux v1.52 Mayhem comparison: proposal only

This package freezes the exact 14 Mayhem build inputs and one official Linux x86_64 v1.52 tool artifact for a controlled comparison. **It is not ready for dispatch:** the unchanged official Agave 2.1.21 SDK has a post-processing selection problem described below. No program build, compiler invocation, runtime probe, source edit, workflow dispatch or initializer investigation occurred in preparing this package.

The 14 source files match both revision `194c4d89f727bbfc7dbfbe7c850bc5e205f6f958` and the accepted Darwin build's recorded inputs. Cargo.lock retains 216 package records, including Anchor 1.0.0. The release profile stays `panic = abort`, overflow checks enabled, LTO disabled, and one codegen unit. No dependency, feature, architecture or compiler-flag variation is proposed. Full file hashes are in `source-inputs.json`; the source files are bundled under `source/`.

The comparison is motivated by a concrete static difference. The original ErrorCode constructor returns the Error tag and box pointer in registers, while current Darwin candidate `9e4e19df…` uses an output pointer. Both bodies allocate the same 160-byte AnchorError payload with agreeing observed field stores. The observed Error enum declarations do not support a dependency-shape correction. The original constructor also references the Linux-style platform-tools `alloc/src/string.rs` path at 2830:14; the candidate references a Darwin-style path at the same coordinate. These facts do not establish an original compiler version, the original program's build host, or the cause of the return convention difference.

The [official v1.52 release](https://github.com/anza-xyz/platform-tools/releases/tag/v1.52) identifies release commit `e3ebfccfe63ba936dd6951ede390496c6bc2f296`. Its Linux asset 310634197 was downloaded in full: 519,270,959 bytes, SHA-256 `8b3861e93daf085ec12b65c4fac374d9bec4587a3de16871da6b08ab0c1d907e`, equal to the publisher digest. Nine selected members were read without execution. The selected alloc rlib contains the original `/home/runner/work/platform-tools/platform-tools/out/rust/library/alloc/src/string.rs` path. The selected source file is byte-identical to the retained Darwin source and has the expected panic expression on line 2830. This is concrete artifact-family evidence, not proof of binary equivalence. All nine member hashes and the official release metadata are retained in `provenance/`; the three small source/version members are bundled in `selected-tool-source/`.

The SDK blocker is specific: the build driver selects v1.52 for compilation, then calls `scripts/strip.sh`, which sources `env.sh`, which invokes `scripts/install.sh`. With a clean SDK dependencies directory, the installer attempts Criterion setup and its v1.43 platform installation. It removes the previously selected platform-tools link before stripping. The CLI's `--tools-version v1.52` does not reach that installer. `sdk-postprocessing-blocker.json` preserves the exact source lines and branch predicates. Consequently the stated unchanged command does not yet guarantee v1.52 post-processing. This report proposes no modified installer, invented completion marker, added compiler version, or stripping workaround; the build owner must resolve the execution scope first.
