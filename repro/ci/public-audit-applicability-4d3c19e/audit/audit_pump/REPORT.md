## Two-curve caller and custody review (C1)

[MultiHopCurve:14–27](inputs/programs/pump/src/multi_hop_curve.rs#L14) requires the fixed AMM global-config PDA **as signer**. An arbitrary transaction signer cannot satisfy that PDA requirement; the intended path needs AMM-mediated CPI. User and source_authority are separate signers. The source token account can be controlled through SPL owner/delegate rules; the output destination is not constrained to user. Native routes consume/pay user lamports while WSOL endpoint accounts serve as routing descriptors. Therefore AMM must establish consent, custody and final slippage; Pump has no minimum-output argument.

For SOL→A→B, flags must be `[1,2]`: user funds root curve C_A in lamports, C_A base A vault transfers A to C_B quote vault, then C_B transfers B to destination. For B→A→SOL, flags must be `[2,1]`: source-authority supplies B to C_B, C_B quote A vault transfers A to C_A base vault using **[bonding-curve,B,bump_B]**, and C_A pays user lamports. The transferred mint A is deliberately distinct from the signing seed mint B. [two_curve_input:175–183](inputs/programs/pump/src/multi_hop_curve.rs#L175), [execute_two:186–278](inputs/programs/pump/src/multi_hop_curve.rs#L186).

Both curves are PDA/owner/discriminator bound, incomplete and noncashback/nonmayhem/nonholder, with exact166-byte layouts and preexisting Tokenkeg82/165 mint/account layouts. Both vaults have canonical ATA address, stored mint and stored curve authority checks. Root/nested mint distinction prevents the ordinary intermediate vault alias that would skip a transfer. Buy output must be strictly less than real reserves; no completion path is admitted. Each hop has checked reserve/fee updates and explicit exit; transaction failure on hop2 must revert hop1. Local fees and reserve transfers are reviewed, but the complete external AMM caller contract remains unclosed. Next prerequisite: parent-reviewed retained AMM route source/byte proof binding custody, input conversion and final slippage for this exact calling convention.

## Transaction and economic assumptions (D2)

This source review did not independently verify the runtime implementation. Events/logs before a later error do not certify committed state. External CPI completion, account aliases, typed-account exit serialization, sufficient backing balances and rent floors must all hold. Nominal token amounts are not a proof of net token conservation for unsupported asset behavior. No Token-2022 extension probe/correction or old unintegrated extension lane was undertaken; the three existing extension helpers receive exclusion-boundary dispositions, not clearance.

The candidate Cargo.toml configures release overflow-checks=true and panic=abort. A plain `+=` is therefore an abort obligation under the configured recipe, not evidence of wrapping arithmetic. Manifest settings alone do not prove executable security or exact compilation. Most fee products are u64×u64 widened to u128; adding9999 remains within u128. Checked narrowing and reserve subtraction reject many invalid states, while unchecked cap divisions still rely on reachable nonzero virtual reserves. Shares normalized to10000 and fee tiers sorted/bounded are external FEES assumptions, not guaranteed by the Pump deserializers.
