# Artifact provenance and licensing

The SDK archive declares MIT licensing. Its source and README retain upstream content and attribution; see `evidence/sdk/registry.json`. The npm package does not include a separate LICENSE file. This repository does not invent a copyright holder or substitute a third-party SDK repository for the unavailable declared upstream repository.

The Pump website bundles, HTML, CSS, font files and derived readable factories are captured third-party materials retained for requested research. Public accessibility is not a grant to relicense or redistribute the entire website as MIT. Individual libraries may retain notices in captured bundles. Review applicable rights and asset licenses before redistributing or deploying derived UI/assets. The local package's `private: true` prevents accidental npm publication; it does not resolve licensing.

Generated factory files are transformations of the byte-indexed original sources, with provenance in `recovered/modules.json`. They do not become original author-owned source. The OpenAPI document is captured from the official public API documentation and is retained with its source metadata.
