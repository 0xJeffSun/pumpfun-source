The initial extra readonly-section audit wrongly rejected .data.rel.ro because its ELF SHF_WRITE flag is set for relocation. Original and candidate use the same .rodata (flags18) and .data.rel.ro (flags3) sections for all eleven references. The final audit checks these observed section identities, reference bytes, pointer targets and bounded payloads; it does not infer runtime permissions from SHF_WRITE alone. This audit correction did not alter source or executables.
