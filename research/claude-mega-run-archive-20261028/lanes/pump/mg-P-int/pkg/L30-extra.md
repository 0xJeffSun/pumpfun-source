## SYNTHETIC LINE POSITIONING (read this first)

Like L12, this is a **layout composite**: `// layout-pad` blank-line blocks hold each `error!`/`require!` Source site on the line the original binary records, and every delivery here was made with line-neutral editing on that layout. Deliveries marked "yes" added or re-laid pad lines (or placed helper functions inside pad blocks / after an end-of-file pad block) to put their own sites on the original lines. **0x178e0** (buy_v2.rs:983, r5-coord-03) is a *placement-only* match: the creator-fee ceil fee's error closure is emitted from an `#[inline(always)]` nested fn on line 983, where the original has the closure of a different op; values and error codes are unchanged, only the reported Source line of that (unreachable for bps <= 10000) Truncation error moves.
