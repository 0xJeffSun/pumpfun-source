## Lineage

Parent: **L12** = `research/claude-pump-integration-20261027/wip-20261028/integ-layout-r37-12` (907/1035 normalized, 165 raw; #401), itself a layout composite on Codex Round37. This package is **L15** = L12 + the newest delivery of each of the 12 round-5 lanes (packet `research/claude-pump-r5-20261028`, #416) composed into one crate (L13, 962) + the 3 windows that only Codex Round46/47 matched (L14, 965) + four mega-run window-lane deliveries made on L13 (L15, 972). Scored with the identity recipe it gains 65 windows over L12 and loses none (normalized and raw).

Composition was a per-file three-way merge (`git merge-file`) of each delivery's crate snapshot against the base it was made on, followed by explicit conflict resolutions (scripts in `tools/`):

- `r5-z00-03` and `r5-z09-01` are contained in `r5-z07-03` (identical files / strict superset).
- `r5-libinst-06` and `r5-z08-03` both moved the Token-2022 `Fee` helpers into a separate dependency crate (the original links such a crate between pump's allocator shim and anchor_spl). The package keeps one crate, `programs/pump/pump-token-ext` (relative path dependency inside the crate dir): libinst's `Fee` + `quote_extensions_supported` with z08's `TransferFeeConfig` / `get_transfer_fee_config` (the `Result<Option<..>,()>` shape z08's `get_transfer_fee` needs).
- `v3_trade_fees` (0x7fde8, libinst) and `v3_post_complete` (0x82af8, z07) only match together when `get_fees` (single caller) returns the `TradeFees` struct (moved to util/fee.rs): a tuple return lost 0x82af8, `.map(..)` lost 0x7fde8.
- create_v2.rs nested_create: z00's function order/positions with z05's pump_quote pricing helpers; z05's and libinst's nested helpers in multi_hop_curve_swap.rs share one layout-pad block (each keeps its Source line).
- Dropped: **0x857a8** (r5-coord-03, trade_v3.rs:997). That gain was a placement of an existing narrowing's error closure; z07 replaced that narrowing with the original's `exact_input_tokens` helper (0x834c8), so the op no longer exists. The original's 997 site is a second u128 narrowing in the v3 buy_exact_quote handler; it is left for a window lane.

## SYNTHETIC LINE POSITIONING (read this first)

Like L12, this is a **layout composite**: `// layout-pad` blank-line blocks hold each `error!`/`require!` Source site on the line the original binary records, and the round-5 / mega deliveries were made with line-neutral editing on that layout. Deliveries marked "yes" above added or re-laid pad lines (or placed helper functions inside pad blocks / after an end-of-file pad block) to put their own sites on the original lines. **0x178e0** (buy_v2.rs:983, r5-coord-03) is a *placement-only* match: the creator-fee ceil fee's error closure is emitted from an `#[inline(always)]` nested fn on line 983, where the original has the closure of a different op (a second `u64::try_from(tokens_for_quote(..))` that this source does not implement); values and error codes are unchanged, only the reported Source line of that (unreachable for bps <= 10000) Truncation error moves. Treat it like the other synthetic positions.

## Build notes

- The nested crate `pump-token-ext` makes the repository dependency cache inapplicable (`pump_dependency_cache.py` refuses local path dependencies), so this package was built by `scripts/pump_build_verified.py --workspace-layout` from a fresh target.
- The lane harness (`claude-pump-work/harness/fastbuild.py`) skips nested `Cargo.toml` files; `tools/fastbuild_nested.py` is the drop-in used for the scores above (same unstripped ELF).
- Toolchain: with the official Linux x86_64 v1.44 `sbpf-solana-solana` target libraries (PR #307; the lane harness identity recipe) this exact source reaches **972/1035 normalized, 165 raw** (unstripped `f4f35346…`). The packaged ELFs use the repository builder's `linux-v1.44-sbf` profile, which gives 967 / 147 raw; the 5 windows it does not reach (`0xce50`, `0x188cc8`, `0x19a1a0`, `0x1a8e28`, `0x1ab9b8`) are `core::error::Error::type_id` / `<T as Any>::type_id` functions whose TypeId constants come from the target-library build, the same gap as #396/#401 (899 vs 894, 907 vs 902).
